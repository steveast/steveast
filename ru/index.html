Тимлид фронтенда · Fasttrack

Февраль 2020 — по настоящее время · удалённо, компания из Москвы

Fasttrack — SaaS-платформа для автоматизации онлайн-коммуникаций: чат-боты, омниканальный чат-центр для операторов, рассылки и интеграции с CRM.

  • Руковожу фронтенд-разработкой основного продукта — конструктор чат-ботов, чат-центр, редакторы рассылок и воронок, аналитика: кодовая база 410 тыс. строк, 96% на TypeScript, более 8 000 моих коммитов с 2020 года.
  • С нуля сделал мобильное приложение чат-центра на React Native (Expo) и за три месяца довёл его от первого коммита до беты для команды. Логика веб-чат-центра переиспользуется через платформонезависимое ядро на TypeScript.
  • Написал 260 из 339 тестовых файлов фронтенда (Jest) — тесты стали обычной частью работы над фичами.
  • Отвечаю за клиентскую архитектуру: MobX, RxJS и внедрение зависимостей (InversifyJS), обновления в реальном времени через Centrifugo (WebSocket), поэтапный переход с Bootstrap на Mantine.
  • Разработал встраиваемые продукты: чат-виджет для сайтов, формы на сайт (около 90% коммитов), VK Mini Apps и виджет для amoCRM.
  • Руковожу командой из четырёх фронтенд-разработчиков: планирование и оценки вместе с PM, код-ревью, онбординг. Менторил джуниора по JavaScript и React.
